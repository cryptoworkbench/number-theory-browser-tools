## The phase-wide rule this plan must satisfy

A tool may keep local custom properties **only if no local declaration contains a literal color**. Every retained declaration's value must be built from `var()` references (optionally wrapped in `color-mix()` or a gradient function). Any hex, `rgb()`, `rgba()`, `hsl()` or named color left in this file — in a token or directly in a rule — is a defect.
