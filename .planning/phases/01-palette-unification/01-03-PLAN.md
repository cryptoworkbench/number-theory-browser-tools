<objective>
Unify the RSA walkthrough tool onto `assets/palette.css`, keeping the Bob / Alice / Eve / discrete-log narrative colors meaningful while retiring its bespoke orange accent.

Purpose: RSA carries the richest *actor* semantics in the repo — four participant colors plus good/bad verdict colors — so it is the strongest test of the role layer's expressiveness (PAL-04). It also contains the phase's clearest day-mode defect: its code wells, notebook grid and lock scrim are hardcoded `rgba(0,0,0,…)` washes that stay black on a light background, so this plan fixes PAL-03 as well as unifying.

Output: `RSA Examplifier/rsa-examplifier.html` rendering entirely from palette tokens in both themes.
</objective>
