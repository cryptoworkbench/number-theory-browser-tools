## The audit rule (phase-level definition of done)

Across `assets/site.css`, `index.html` and all five tool HTML files:

1. No hex, `rgb()`, `rgba()`, `hsl()` or named-color literal outside CSS comments and the Google Fonts `<link>`.
2. Every retained local custom property declaration has a value built only from `var()` references, `color-mix()`, gradient functions, or non-color values (lengths, numbers).
3. Every page links `assets/palette.css` on a line before its `assets/site.css` link.
4. `assets/palette.css` is the only file in the repo declaring literal color values.

Expected retained local declarations after plans 01-01 through 01-04, and nothing else:

| File | Retained local declarations |
|------|----------------------------|
| `Sieve Of Eratosthenes/sieve-of-eratosthenes.html` | `--cell-min` (a length, written at runtime by JS) |
| `Christmas Trees/factor-tree.html` | `--sky-opacity` (a number), `--page-bg`, `--pine-grad-1`, `--pine-grad-2`, `--trunk-grad-1`, `--trunk-grad-2` (all pure palette derivations) |
| `assets/site.css` | the seven `--st-*` tokens (all pure palette derivations) |
| `index.html`, `Pizza Slices/pizza-slices.html`, `Factorize By Completing The Square/factorize-completing-square.html`, `RSA Examplifier/rsa-examplifier.html` | none |

## The role-meaning matrix to confirm (PAL-04)

| Meaning | Token | Where it must now appear |
|---------|-------|--------------------------|
| the computed answer | `--role-result` | Sieve primes; tree prime leaves; completing-the-square success; RSA success verdict |
| a user input / the value being operated on | `--role-input` | tree composite nodes; RSA Bob; Congruence Wheel selected class (via `--accent`) |
| the current step | `--role-active` | Sieve current multiple; tree fairy-light accent |
| eliminated / inert | `--role-inert` | Sieve composites; tree terminal `1` nodes and trunk |
| error / adversary | `--role-warn` | Sieve validation error; tree error message; completing-the-square failure; RSA Eve and failure verdict |
| an advanced or optional concept | `--role-special` | Sieve secondary accent; completing-the-square advanced step; RSA discrete-log aside |
| a second participant / edge case | `--role-alt` | Sieve `1` cell; RSA Alice |
