**Strip structure and CSS — the architectural core.** Build the strip as plain `<div>` elements in CSS Grid, mirroring `Sieve Of Eratosthenes/sieve-of-eratosthenes.html` lines 213-279 and 563-579, not as SVG and not with the `svgEl` helper: 03-RESEARCH.md Pattern 1 chose the DOM-grid idiom precisely so none of this diagram is hand-drawn.

- `#stripBody` holds one `.strip-row` per congruence plus one final `.strip-row.agree-row`. Each `.strip-row` is itself `display:grid`, and every row is assigned the SAME `gridTemplateColumns` string from JS — `var(--label-w) repeat(<span>, var(--cell-min))`. That identical template across rows is the entire mechanism behind D-01's "solution reads as a vertical alignment": no per-cell pixel maths, no manual offsets. Do not build one large grid with manually indexed rows and columns — 03-RESEARCH.md's anti-pattern section rejects that shape because rows drift apart when their heights differ.
- `--label-w` is declared once on `#stripBody` as a fixed length (`132px`) so the label column is the same width in every row; a content-sized label column would break the alignment the moment two labels differed in length. `--cell-gap` is declared the same way as a fixed `3px` and is also read back into JS as a plain constant, because the cursor auto-scroll needs the cell pitch as a number. Both are non-colour local custom properties, which is the allowed exception.
- `.strip-label` is the first cell of every row and carries `position:sticky; left:0; z-index:2` with an opaque `background:var(--bg-2)` — the same sticky-header device `Cayley Table/cayley-table.html` uses at its lines 127-135, and the opaque background is required or the scrolled cells show through it. Its text is the congruence in mono (`x ≡ 2 (mod 3)`), and for the agreement row it reads `all agree`.
- `.strip-cell` is square (`width` and `height` both `var(--cell-min)`), centred, `border-radius:6px`, with the Sieve's base treatment: a `color-mix` wash of `var(--text)`, a `color-mix` border, `color:var(--text-dim)`, `font-variant-numeric:tabular-nums`, `font-size: clamp(8px, calc(var(--cell-min) * 0.42), 13px)`, and a transition on background, border-colour, colour and box-shadow. Its text content is its own `x`, and it carries `data-row` and `data-x` attributes; the gates and the harness both read those.
- State classes, declared in this order so the later rule wins on a cell that carries several: `.strip-cell.is-residue` fills with `--slot-res-soft` and borders and colours with `--slot-res`; `.strip-cell.is-cursor` borders and colours with `--slot-cursor` plus a `box-shadow` ring built from `color-mix` of the same token; `.strip-cell.is-agree` fills with `--slot-sol-soft`; `.strip-cell.is-solution` fills solid `--slot-sol` with `color:var(--role-result-ink)` and `font-weight:700`.
- `#stripScroll` is `overflow-x:auto; overflow-y:hidden` with the panel's border and radius, and `#stripBody` is `width:max-content; min-width:100%` so the rows scroll together as one block.
