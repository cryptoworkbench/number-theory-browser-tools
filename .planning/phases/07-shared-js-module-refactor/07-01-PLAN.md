## Architecture contract (decided in planning; every plan in this phase follows it)

- Module files: `assets/nt-<name>.js` defines exactly one sub-namespace `window.NT.<name>`. Five modules this phase: nt-core → NT.core, nt-bigint → NT.bigint, nt-svg → NT.svg, nt-store → NT.store, nt-layout → NT.layout. Phase 6's translations will follow the same rule (nt-i18n → NT.i18n).
- Module shape: classic script, one IIFE, "use strict", opens with a theme.js-style header comment (what it centralizes, which tools consume it, the include + import convention); obtains the root with `var NT = window.NT = window.NT || {};`; defines functions; ends by assigning `NT.<name> = Object.freeze({ ... })`. No DOM access at load time. nt-layout throws a descriptive Error at load if NT.core is absent.
- Page include: plain `<script src="../assets/nt-<name>.js"></script>` lines (no defer, no async, no type=module — pages must run over file://) placed on their own lines immediately before the tool's inline `<script>` at the end of body, in canonical order core, bigint, svg, store, layout; only modules the tool imports (plus nt-core whenever nt-layout is included). The deferred theme.js include in head is untouched.
- Tool import block: the first statements of the tool's script scope (after the "use strict" directive when present, else directly after the IIFE opening line; RSA's script has no IIFE, so after its top-level directive) — a section-marker comment line `/* ---------- shared helpers (assets/nt-*.js) ---------- */` followed by one `const { a, b } = NT.<ns>;` line per namespace in canonical order, names sorted by Array.prototype.sort default order (uppercase constants before lowercase). Call sites keep calling bare names; renamed near-duplicates are renamed at their call sites to the canonical name. Tools never assign to NT or its members.
- BASE: the pre-phase commit = parent of the commit that first added assets/nt-core.js (`git log --diff-filter=A --format=%H -- assets/nt-core.js`, last line, then `^`); while nt-core.js is still uncommitted, BASE = HEAD. Every OLD function body and every OLD page snapshot is read from BASE via git show — never from the working tree.
- Commit messages for module-creating commits state that shared JS logic modules are being introduced deliberately (root CLAUDE.md guidance).
</context>
