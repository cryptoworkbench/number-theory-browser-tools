<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| document.cookie / localStorage → NT.store readers | Persisted values may be stale, hand-edited or written by another page; they are untrusted input |
| location.search → readModeNParams / readABParams | Deep-link parameters are attacker-controllable text |
| NT.store writers → persisted cross-tool contract | Other pages (and browsers holding pre-phase values) read what these write |
