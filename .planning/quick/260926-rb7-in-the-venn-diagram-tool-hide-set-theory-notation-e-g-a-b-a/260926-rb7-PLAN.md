<objective>
In `Venn Diagrams/venn-diagrams.html`, stop rendering set-theory notation as the permanent region captions on both diagrams. Each region caption becomes plain English, and the notation moves into a native browser tooltip that appears on hover.

Purpose: the notation is the thing a self-directed learner has not learned yet. Showing `A \ (B ∪ C)` under a circle at all times reads as noise to the reader who most needs the tool; on demand, the same string is a useful lookup. The lede prose keeps the notation and teaches it, the diagram stays readable, and the tooltip is the bridge between them.
Output: `Venn Diagrams/venn-diagrams.html` with plain-word captions and 13 notation tooltips (10 region groups + 3 two-circle captions).

**Implementation note on "the title attribute" — read this first:**
The request asks for a tooltip "using the title attribute". Every caption and region in this tool is an **SVG** element, and SVG does not honour the HTML `title` *attribute* — `setAttribute('title', ...)` on an SVG node renders no tooltip and is inert in every browser. The SVG mechanism that produces exactly the requested native browser tooltip is a `<title>` **child element**. This plan therefore uses `<title>` child elements. That is the faithful implementation of the intent (native browser tooltip, no custom hover UI, no JS positioning), not a substitution of a different mechanism. Do NOT also set a dead `title` attribute alongside it.

**Scope discipline — do NOT touch these:**
- **Both lede paragraphs (`#lede-two`, `#lede-three`) keep their notation verbatim.** They are the teaching text that tells the reader what `A \ B` means; stripping them would leave the tooltips unexplained. An automated gate asserts the two-circle lede still contains both `A ∩ B` and `A \ B`.
- **The product / GCD readout rows keep their `∩` infix verbatim** (`A ∩ B = 12 ∩ 18 = 6`, etc.). That infix was introduced deliberately by quick task 260926-eod; reversing it is not in this item's scope. An automated gate asserts the `#product-overlap` row still matches its notation shape. If it turns out the reader wants those rows tooltip-ified too, that is a follow-up item — the human check below asks the question without acting on it.
- Do NOT change the circle name labels (`A`, `B`, `C`), the mode switch, the prime picker, the palette, region caps, geometry constants, caption anchors, storage keys, or any color. No CSS color declaration is added or edited by this plan.
- Do NOT reposition any caption. The captions keep their exact current `x`/`y` anchors; only their text and (for the three two-circle ones) their pointer behaviour change.
