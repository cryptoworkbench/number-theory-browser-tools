<objective>
Make group type (additive vs multiplicative) and modulus N a single setting shared by the Cayley Table and the Equivalence Wheel, persistently and in both directions, instead of two private per-tool settings that overwrite each other's meaning.

Purpose: the two tools are two views of the SAME group — the Wheel shows Z/NZ (or its units) as sectors, the Cayley Table shows it as an operation table, and they already cross-link to each other both ways. Today, setting the Wheel to additive mod 18 and then opening the Cayley Table lands on an unrelated multiplicative mod 6, because each tool restores its own private record. After this change, the tool you open shows the group you were just looking at.

Output: two edited single-file tools. No new files, no shared JS module, no new dependency, no algorithm moved between files.
</objective>
