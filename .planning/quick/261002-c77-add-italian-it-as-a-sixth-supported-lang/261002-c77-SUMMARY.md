## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Two LANG-COUNT-DOCS false negatives in the gate sweep itself**
- **Found during:** Task 2's consolidated-doc verify rerun
- **Issue:** (a) `i18n-check.js`'s own `LANG_CODES` comment wrapped `nl, en, de, fr, es,` onto one line and `// it` onto the next, so the LANG-COUNT-DOCS regex's negative lookahead for `, it` never matched across the line-wrap join. (b) `06-GLOSSARY.md`'s Euler proper-noun row used `nl/de/fr/es` (no `/it`), tripping the same five-language-list pattern.
- **Fix:** Reworded both to avoid the regex's exact trigger shape (comment rewritten to put the full list on one unbroken clause; glossary row reworded from a slash-list to a comma list naming Italian explicitly).
- **Files modified:** `.planning/phases/06-multi-language-support/i18n-check.js`, `.planning/phases/06-multi-language-support/06-GLOSSARY.md`
- **Commit:** `00db417`

**2. [Rule 1 - Bug] rsa.js inline `MCD(...)` casing inconsistent with the file's own established convention**
- **Found during:** Task 3, drafting rsa.js's Italian block
- **Issue:** My first draft used uppercase `MCD(...)` for the inline function-call-style notation (e.g. `MCD(65537, φ(n)) ≠ 1`), but every other language in this specific file uses lowercase for this usage (nl `ggd(`, de `ggT(`, fr `pgcd(`, es `mcd(`) — uppercase would have been the only outlier in that file's rows, even though a different file (euclid.js) legitimately capitalizes `il MCD` as a standalone noun per the fr `PGCD` precedent.
- **Fix:** Lowercased all 5 occurrences in rsa.js's Italian block to `mcd(`, matching the file's own inline-notation convention.
- **Files modified:** `assets/i18n/rsa.js`
- **Commit:** `38b2f1b`

Three new IDENTICAL-TO-EN findings surfaced because the matching Italian word happens to be a genuine cognate of English, same as the French/Spanish/Dutch cognates this project's gate scripts already exempt. Each was resolved by adding or extending a per-key `allowSame`/`allowRenderText` reason string — never by loosening the gate's logic:

| `i18n-config/cayley-table.json` | `cayley.identityWordAdditive` | "zero" | New entry added (no prior language collided on this key) |

| `i18n-config/shors-algorithm.json` | `shor.legendBase` / rendered `"base a"` | "base" | Extended existing fr/es reason to also name Italian |
