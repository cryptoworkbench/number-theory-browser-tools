- **Found during:** Task 2 (`euclid.chipFibonacciWorst`/`euclid.caption` → Fibonacci; `ecdh.pillHasse` → Hasse), Task 3 (`rsa.crtRecombinationHeading` → Garner; `shor.detailOrderFind`/`explainerP1`/`introP2`/`standInCaption` → Fourier)

- **Fix:** Added `Fibonacci`, `Hasse`, `Garner` and `Fourier` to the shared `SCRIPT_LATIN_NOTATION` array in `i18n-check.js` (not an el-only list, since both ru and el treat these the same way) rather than inventing a transliteration no other language uses; also reverted an initial Cyrillic transliteration of Fibonacci (`Фибоначчи`) back to the literal Latin spelling for consistency with the other fourteen languages' own convention.
- **Files modified:** `.planning/phases/06-multi-language-support/i18n-check.js`, `assets/i18n/euclidean-algorithm.js`
- **Verification:** `i18n-check.js --coverage` scoped to each namespace returned zero findings after each fix; SCRIPT-GATE's 19 synthetic checks and SCRIPT-SWEEP's real-data checks both still pass after the allow-list grew.
- **Committed in:** `6a8d609` (Task 2, Fibonacci/Hasse), `c30ae5e` (Task 3, Garner/Fourier) — each fix is part of its own task's single commit, not a separate commit.

**2. [Rule 1 - Bug] Six Russian values dropped the literal "mod" token every other language keeps**

- **Fix:** Reworded each to keep `mod` literal (e.g. "обращает e mod φ(n)", "Цикл a mod N"), matching Q-09's rule that `mod` stays literal in every key where every existing language keeps it.
- **Files modified:** `assets/i18n/rsa.js`, `assets/i18n/shors-algorithm.js`

**3. [Rule 1 - Bug] Four values used the loanword "bit"/"Bit"/"modulo" inconsistently with the per-language allow-list**
- **Found during:** Task 2 (`hub.card.dh.desc` el "byte" not on the allow-list), Task 3 (`sqm.legend.bit`/`stepHeading`/`bannerStepMultiplied`/`bannerStepSkipped` el capitalized "Bit"; `shor.cycleRingAriaLabel` el "modulo")
- **Issue:** `SCRIPT-LATIN` correctly flagged a capitalized `Bit` (the allow-list entry is lowercase `bit` only) and the full word `modulo` (only the abbreviation `mod` is on the notation allow-list) and the untransliterated English loanword `byte`.
- **Fix:** Lowercased/rephrased each sentence to avoid a sentence-initial bare loanword (e.g. "Το bit {i} από {total}…"), abbreviated `modulo` to `mod`, and transliterated `byte` to the established Greek loanword `μπάιτ` (Russian already used its own `байт`).
- **Files modified:** `assets/i18n/hub.js`, `assets/i18n/square-and-multiply.js`, `assets/i18n/shors-algorithm.js`
- **Verification:** `i18n-check.js --coverage` scoped to each namespace returned zero findings after each fix.
- **Committed in:** `6a8d609` (Task 2), `c30ae5e` (Task 3)

**4. [Rule 1 - Bug] One Greek key used an elision apostrophe forbidden by Q-06**

- **Fix:** Rewrote each to the full non-elided form (`αντί αυτού`, `για αυτό`) before committing — caught during drafting, not by an automated gate (no gate currently checks for this specific orthographic rule), so recorded here for completeness.
- **Files modified:** `assets/i18n/square-and-multiply.js`, `assets/i18n/shors-algorithm.js`, `assets/i18n/rsa.js`
- **Verification:** Manual re-read of every Greek value containing "αυτ" before each namespace's commit.
- **Committed in:** `6a8d609` (Task 2), `c30ae5e` (Task 3)
