<objective>
Add Undo and Redo icon buttons to (a) the shared number palette and (b) the working area, on both Factor Tree and Venn Diagram. Read the user's "do and undo" as Redo and Undo.

Orchestrator decisions, treated as locked and cited by ID below:
- D-01: Each page has two independent histories: the number palette (NT.store's number-palette list, shown in Factor Tree's `.palette` and Venn Diagram's `.prime-picker`) and the working area (Factor Tree's composition/factorization area with its trees; Venn Diagram's placed primes, including the effects of Clear and Randomize). Each gets its own Undo and Redo icon button.
- D-02: History is snapshot-based and kept in memory for one page load (not persisted). Every user action that changes that state pushes the previous snapshot onto the undo stack and clears the redo stack. Undo/Redo restore snapshots and re-render without resetting unrelated tool state. Stacks hold at most about 100 entries.
- D-03: Palette Undo/Redo write the restored list back to the shared store, through a new `writeSharedPalette(list)` export in assets/nt-store.js that follows the module's validation/frozen-export pattern (not a clear-then-add emulation). A palette change arriving from another tab (storage event) clears that page's palette history (both stacks).
- D-04: The buttons are compact icon buttons (curved-arrow SVG, stroke = currentColor), styled like the existing `.palette-empty-btn`, with the same disabled look when their stack is empty. The palette pair sits in the palette's Add row with the bin/Delete-all tools. The working-area pair sits in the working-area header next to Clear (Factor Tree) and with the diagram controls (Venn Diagram). Colours come only from var() tokens.
- D-05: aria-label + title translated in all sixteen languages, as shared `common` keys in assets/i18n/site.js, bound through data-i18n-aria-label / data-i18n-title like the bin. Russian and Greek in their own script. Keyboard: Ctrl/Cmd+Z = undo, Ctrl/Cmd+Shift+Z or Ctrl+Y = redo, for the WORKING AREA only, and ignored while focus is in a text/number input.
- D-06: Verification: i18n-check.js (every mode that passes today must still pass) plus a browser check on a local `python3 -m http.server` bound to 127.0.0.1 (not file://, so the user's real localStorage stays untouched). Exercise palette add/remove + undo/redo and work-area place/unfold + undo/redo, and check the buttons disable correctly. - D-07: Commit only the files this task changes (the working tree has unrelated untracked files), with the two trailer lines given in the task description.
