- L-SOURCE: English is the source of truth. Translate every value from its en entry (never from he or any other language). Every key of every namespace gets a Hindi value; no key is skipped, shortened or left English.
- L-PLURAL: Hindi plural values use exactly the categories `new Intl.PluralRules('hi').resolvedOptions().pluralCategories` returns: verified in this repo's Node 22.23.1 (ICU 78.2, CLDR 48) as one, other. CLDR's Hindi `one` is "i = 0 or n = 1", so 0, 0.5 and 1 select one and 1.5, 2, 3, 10, 1000000 select other. The `one` form must therefore read correctly for 0 as well as 1, and keep every placeholder (the count is never written as the word for one). No PLURAL_EXTRA_CATEGORIES entry is needed.
- L-LTR: Hindi is left-to-right. It is not added to RTL_LANGS (engine or checker); no dir attribute, no :root[dir="rtl"] rule, no bidi isolate or mark in any Hindi value.
- L-DIGITS: Hindi values use ASCII digits 0-9 only, never Devanagari digits (U+0966-U+096F), and are never locale-formatted: no Indian lakh/crore grouping (12,34,567), no comma decimal. Each Hindi value carries exactly the numerals of its English value (same digits, same grouping commas, same decimal point, any order). English scale words become मिलियन/बिलियन/ट्रिलियन so the numeral stays as in English (16.8 मिलियन, 1 ट्रिलियन); never convert to लाख/करोड़/अरब.
- L-DETECT: browser detection is case-insensitive and maps hi, hi-IN, HI_in etc. to hi through the engine's existing lowercased two-letter path (no new branch). setLang/?lang=/cookie/storage accept only the exact code hi.

## Discretion choices made here (recorded so every batch stays consistent)

- D-REGISTER: formal-polite आप register, the convention of Hindi software UIs: polite imperatives for instructions and buttons (चुनें, दबाएँ, क्लिक करें, दर्ज करें, देखें, आज़माएँ, खींचें, चलाएँ, रोकें, रीसेट करें, बनाएँ); verb agreement with आप uses the standard masculine-plural honorific default.
- D-ORTHO: standard spelling of the Central Hindi Directorate: anusvara for a nasal before a consonant of its own class (संख्या, खंड, संबंध, अंक); chandrabindu where no vowel sign rises above the headline (एँ, हाँ) and anusvara where one does (करें, में); nukta for borrowed sounds (फ़, ज़) in loanwords and eponyms; ऑ for the borrowed open o (ऑयलर). Every value is NFC (precomposed nukta letters U+0958-U+095F decompose under NFC) and contains no zero-width joiner, non-joiner or other zero-width character.
- D-PUNCT: a Hindi prose sentence ends with the purna viram । (U+0964, written as the literal character); the double danda ॥ is never used; "." stays inside numerals, abbreviations (म.स.), formulas and the ellipsis "…". ? ! : ; , as in English with no space before them; ASCII double quotes around a quoted UI label ("चलाएँ"); dash " — " with spaces. Math notation, arrows (→ in "Open tool →" stays →) and playback glyphs ▶ ⏸ ⏭ ⏩ ↺ are unchanged. A value whose English has no closing punctuation gets none.
