## Locked decisions (orchestrator + user + precedent)

- L-SOURCE: English is the source of truth. Translate every sq and every sw value from its en entry. Never derive Albanian from Swahili, either from an existing block, or one batch's wording from machine-like transliteration of another language (SHARED-VALUES gate). Every key of every namespace gets a value in both; no key is skipped, shortened or left English.
- L-STANDARD: sq is standard Albanian (gjuha standarde, the Tosk-based literary norm, 1972 orthography): no Gheg forms (no nasal vowels â ê î ô û, no Gheg infinitive "me" + participle). sw is Kiswahili sanifu (Standard Swahili, BAKITA/TUKI conventions): no Sheng, no English code-mixing.
- L-PLURAL: `new Intl.PluralRules('sq'|'sw').resolvedOptions().pluralCategories` is one, other (verified in this repo's Node 22.23.1). one selects exactly 1 (Swahili: integer 1 only); 0, 2, 1.5, 21, 100 and 1000000 select other (unlike Hindi and French, 0 is other). PLURAL_EXTRA_CATEGORIES gets no entry for either. Every category keeps every placeholder; the count is never replaced by a word.
- L-DIGITS: ASCII digits only, never locale-formatted: no space or dot thousands grouping (Albanian's own 16 777 216 / 16,8 convention does not apply), no comma decimal. Each sq and sw value carries exactly the numerals of its English value (same digits, grouping commas and decimal point, any order). sq and sw join DIGIT_PARITY_LANGS: the checker's own rule is that the list holds the languages added after the digit-parity rule existed (Hindi, Arabic), which both are; the alternative (leaving them out) would leave the user's explicit "keep literal English numerals" requirement ungated. Scale words: sq milion / miliard / trilion (16.8 milionë), sw milioni / bilioni / trilioni with the numeral after the word as Swahili requires (milioni 16.8); the numeral itself stays exactly as in English.
- L-LTR: both are left-to-right; neither joins RTL_LANGS (engine or checker). sq and sw values contain no U+2066-U+2069 isolate, no U+200E/U+200F mark and no U+202A-U+202E embedding (BIDI-MARK gate). Switching from he or ar to sq or sw removes the dir attribute (existing applyHtmlLang behavior, asserted).
- L-FONT: no font change. ë Ë ç Ç are Latin-1 letters inside the latin subset of the three Google Fonts every page already loads (Source Serif 4, Source Sans 3, JetBrains Mono); French values already render ç and Dutch values ë in them. Swahili is plain ASCII. Add no Google Fonts link, @font-face or font-family anywhere.
- L-DETECT: browser detection maps sq, sq-AL, SQ_xk, sq-MK and sw, sw-KE, SW_tz, sw-CD (any region, any case, - or _) through the engine's existing lowercased two-letter path; no new branch (verified during planning on a scratch copy with only the SUPPORTED_LANGS change: all map). - D-REGISTER-sw: instructions and buttons use the singular imperative, the convention of Swahili software UIs: bofya, chagua, ingiza, andika, tazama, jaribu, buruta, bonyeza, sogeza; Cheza, Sitisha, Weka upya, Tengeneza, Futa, Ongeza, Hamisha, Tendua, Rudia; validation messages state the problem (… lazima iwe …); status banners use the perfect or stative (Zimepatikana …, Imekamilika).

- D-GRAMMAR-sq: gender, number, definiteness and case agree with the noun actually named. Acronyms stand in apposition (çelësi RSA, algoritmi RSA), never with a hyphenated suffix. The numeral precedes the noun ({count} hapa). A frame and the words fed into its slot ({word} in cayley/wheel, {roles} and {verbing} in wheel, {ordWord} in ecdh) are translated together so gender and definiteness agree; a slot of unknown gender uses a construction that needs no agreement.
- D-GRAMMAR-sw: noun-class agreement (connector -a, adjectives, demonstratives, verb subject and object prefixes) follows the noun actually named. Numerals follow the noun (hatua {count}, namba tasa {count}); ordinals are hatua ya {index}. Names and placeholders never change form; a possessive uses the connector of the possessed noun's class (ufunguo wa umma wa {0}, jozi ya funguo ya {0}). Frames and slot words are translated together; a slot of unknown class uses a label form (… : {word}) or a construction whose agreement does not depend on the slot.
