## Locked decisions (orchestrator; non-negotiable)

- L-CODES: Kurmanji is code `ku`, switcher label `Kurmancî`; Sorani is code `ckb`, switcher label `کوردی` (U+06A9 U+0648 U+0631 U+062F U+06CC). Both are appended after zgh-Tfng in that order: SUPPORTED_LANGS, SWITCHER_OPTIONS, the page switchers and every data file (ku then ckb are the last two language blocks everywhere).
- L-SHAPE: ckb is a plain three-letter code with no subtag, a new shape, matched exactly and case-sensitively like every other code (valid() is unchanged). The engine header comment, the checker header comment and the docs describe it as "the three-letter `ckb`" next to the region-tagged pt-BR/pt-PT and the script-tagged zgh-Latn/zgh-Tfng. checkSwitcherPresent's option regex already accepts it (measured).
- L-RTL: ckb is right to left: it joins RTL_LANGS next to he and ar in the engine and the checker, so `<html lang="ckb" dir="rtl">`, every existing :root[dir="rtl"] rule applies unchanged, and BIDI-FORMULA covers ckb. ku is left to right (no dir; switching from he, ar or ckb removes it).
- L-DETECT: browser detection: `ckb` (any region, script or case, `-` or `_`) → ckb; a `ku` tag with an `Arab` script subtag (ku-Arab, ku-Arab-IQ, any case) → ckb; `kmr` (any subtags) → ku; every other `ku` tag (ku, ku-TR, ku-Latn, ku-IQ, ku-IR) → ku through the existing two-letter fallback. `sdh` (Southern Kurdish) and `lki` are not mapped. The new branch runs directly after the zgh/tzm/ber branch, before the two-letter slice. Collision notes, measured during planning (GATE engine) and to be recorded like the kok/jam/ido precedents (T-k7u-02):
  - Once ku is supported, the slice maps every three-letter primary subtag starting with ku to ku: kur (ISO 639-2 Kurdish, intended), but also kum (Kumyk), kua (Kuanyama) and the like; kur-Arab also gives ku (only the ku primary subtag is checked for Arab).
  - ckb-Latn gives ckb (any ckb tag is Sorani); kmr-Arab gives ku (kmr is always Kurmanji).
  - ckbx, kmrx, ck and sdh fall through as before (slices ck, km, sd are not supported codes).
- L-SCRIPT-KU: Kurmanji uses the Latin Hawar alphabet a b c ç d e ê f g h i î j k l m n o p q r s ş t u û v w x y z, NFC precomposed ç ê î ş û (ş is U+015F, never the Romanian ș U+0219; no Turkish ı, ğ, ö, ü). Any other non-ASCII letter is rejected unless the English value has it (Bézout's é); φ is always allowed (the zgh precedent). New permanent checker finding KU-LETTER.
- L-SCRIPT-CKB: Sorani uses exactly the 33 letters of the Kurdish Arabic-based alphabet, CKB_LETTERS: ئ ا ب پ ت ج چ ح خ د ر ڕ ز ژ س ش ع غ ف ڤ ق ک گ ل ڵ م ن ھ ە و ۆ ی ێ (ک U+06A9, ی U+06CC, ە U+06D5, ھ U+06BE for h; û is written وو). ARABIC-LETTER becomes per-language: for ckb, any Arabic-script letter outside CKB_LETTERS (so Arabic ك U+0643, ي U+064A, ى U+0649, ة U+0629, ه U+0647, the hamza seats أ إ آ ؤ ء and the Arabic-only consonants ث ذ ص ض ط ظ); for ar and every other language, the existing U+0621..U+063A / U+0641..U+064A rule unchanged (still banning ک ی ە for ar). Sorani writes vowels as letters, so TASHKEEL (harakat), TATWEEL and PRESENTATION-FORM stay banned for every language. SCRIPT_RULES.ckb mirrors SCRIPT_RULES.ar (own = an Arabic-script letter, the same foreign pattern, latin = SCRIPT_LATIN_NOTATION). Isolates (U+2066…U+2069) are required wherever the he or ar value of the same key has them; the BIDI findings extend to ckb through RTL_LANGS.
- L-PLURAL: both use { one, other }. Intl has CLDR data for both (Node 22.23.1 / ICU 78.2 / CLDR 48 and Chrome 153, also with LANG=ru_RU: one for exactly 1, other for 0, 1.5, 2, 21, 100, 1000000; supportedLocalesOf gives ku and ckb; kmr resolves to ku). No FIXED_PLURAL_LANGS entry, no PLURAL_EXTRA_CATEGORIES or PLURAL_OTHER_ONLY_LANGS entry; expectedPluralCategories stays one, other.
- L-DIGITS: ASCII digits only, literally the English numerals (comma grouping, dot decimal) in both; never Arabic-Indic ٠-٩, never Extended Arabic-Indic ۰-۹ (the digits Sorani print commonly uses), never ٫ U+066B or ٬ U+066C, never ، inside a numeral. Both join DIGIT_PARITY_LANGS (NATIVE-DIGIT and NATIVE-SEPARATOR already apply to every language).
- L-FONT: system fallback only: no font link, @font-face or font-family change (a locked project rule; do not raise it). The test machine has Noto Sans Arabic, Noto Naskh Arabic and Vazirmatn covering all 33 Sorani letters (GATE font); Kurmanji's letters are Latin-1 / Latin Extended-A, covered by the existing webfonts.

- D-REGISTER-KU: Kurmanji UI register, no pronoun unless unavoidable: instructions and verb buttons in the second person singular imperative (Hilbijêre choose, Binivîse enter/type, Bitikîne click, Zêde bike add, Jê bibe remove, Paqij bike clear, Hesab bike compute, Nîşan bide show, Veşêre hide, Bi kar bîne use, Bikişîne drag, Temaşe bike watch, Biceribîne try, Lêxe play, Rawestîne pause); noun buttons stay nouns (Gav for Step); validation states the requirement (Divê … be); status banners in the past or passive (… hate dîtin found, … qediya completed, … hate hesabkirin computed). Alice and Eve take wê, Bob takes wî where a pronoun is unavoidable.
- D-REGISTER-CKB: Sorani UI register (the ar precedent): instructions in the second person singular imperative (ھەڵبژێرە choose, بنووسە enter/type, کرتە بکە click, زیاد بکە add, لابە remove, پاک بکەرەوە clear, بژمێرە compute, پیشان بدە show, بشارەوە hide, بەکاربھێنە use, ڕابکێشە drag, سەیر بکە watch, تاقی بکەرەوە try); buttons and toggles as verbal nouns (لێدان, ڕاگرتن, ڕێکخستنەوە, سڕینەوە); validation دەبێت … بێت; status in the past (دۆزرایەوە found, تەواو بوو completed). Sorani has no grammatical gender.
- D-ORTHO-KU: Hawar spelling of the pinned forms (algorîtm, fonksiyon, kilît, şîfre, matematîk, îzomorfîzm, elîptîk); ezafe by gender and number (hejmara seretayî, razê hevpar, kilîtên giştî) and the free linker ya/yê/yên after a token that cannot take the suffix (fonksiyona φ ya Euler); oblique plural -an (grûpan, hejmaran); sentence-initial capital only, nationality adjectives lowercase (çînî).
- D-ORTHO-CKB: standard Sorani Unicode orthography: every word-initial vowel takes ئ first, word-initial r is ڕ, no word starts with ڵ (CKB-INITIAL); ezafe ی attached to Kurdish nouns (کلیلی گشتی), ییی-free double ی after î (نھێنیی ھاوبەش); definite ەکە / plural ەکان attached; vowels written as letters, so no haraka anywhere; NFC, no zero-width character (a ZWNJ is never needed: ە and the other non-joining letters already break the join).
- D-PUNCT: ku uses English punctuation; ckb uses ، (U+060C), ؛ (U+061B) and ؟ (U+061F) as literal characters, never ASCII , ; ? after an Arabic-script letter and never the Urdu full stop ۔ (CKB-PUNCT); full stop ".", colon ":" and "!" stay ASCII; ASCII punctuation stays inside formulas, numerals and token lists. Both quote with «…» (no inner spaces) and use no apostrophe or ASCII/typographic quote at all (QUOTE-STYLE); no space before : ; ? ! (or ، ؛ ؟); the dash spaced exactly as in English; the ellipsis … as in English; a value whose English has no closing punctuation gets none.
- D-ISOLATES (ckb, as he/ar): every numeric formula, equation, comparison, fraction, mod expression and coordinate/argument tuple inside a Sorani sentence is wrapped in <LRI>…<PDI> in the draft; a Sorani phrase inside an LTR-forced box gets <RLI>…<PDI> exactly where both he and ar use U+2067 (CKB-NO-RLI).
