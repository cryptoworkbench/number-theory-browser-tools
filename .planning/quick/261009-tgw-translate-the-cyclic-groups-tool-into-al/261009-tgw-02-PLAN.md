  `: ; ? !`). Existing terms: sous-groupe, ordre, élément neutre, Opération de groupe, Table de Cayley,
  Réinitialiser, générateur, groupe cyclique. Hints: collier (necklace), classe latérale (coset), orbite, corde,
  cardinal (cardinality), polygone. Traps (brief section 3): `fact.structure`, `opAdd` and `opMul`. French math
  prose writes "modulo" (`crt.coprimeOk.fr`), so "addition modulo {n}" is natural. Decide on "Structure" (a
  genuine cognate) yourself and record the choice.
- es: informal **tú**, with ¿…? and ¡…! where questions or exclamations occur. Sentence case. Existing terms:
  subgrupo, orden, identidad, Operación de grupo, Tabla de Cayley, Reiniciar, generador, grupo cíclico. Hints:
  collar, clase lateral, órbita, cuerda, cardinalidad, polígono.
- it: informal **tu**. Existing terms: sottogruppo, ordine, elemento neutro, Operazione di gruppo, Tavola di
  Cayley, Reimposta, generatore, gruppo ciclico. Hints: collana, classe laterale, orbita, corda, cardinalità,
  poligono.
- pt-BR: **você** with third-person imperatives (clique, escolha, arraste), Brazilian spelling and vocabulary.
  Existing terms: subgrupo, ordem, elemento neutro, Operação do grupo, Tabela de Cayley, Reiniciar, gerador,
  grupo cíclico. Hints: colar, classe lateral, órbita, corda, cardinalidade, polígono. The download wording
  follows `wheel.exportPngBtn` pt-BR.
- pt-PT: **tu** with second-person imperatives (clica, escolhe, arrasta), European spelling and vocabulary.
  Repor is common.reset. Other terms as pt-BR where the existing pt-PT values agree. The download wording
  follows `wheel.exportPngBtn` pt-PT. Never copy a pt-BR value into pt-PT without checking that it is also
  correct European Portuguese.
