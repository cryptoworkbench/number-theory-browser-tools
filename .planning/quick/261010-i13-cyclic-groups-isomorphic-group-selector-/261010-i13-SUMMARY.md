## noshare=1 design note

A plain `?mode=&n=` link makes loadState call `persistGroup()`, writing localStorage `group-params`; the page's `storage` listener then switches every other open tab of the tool to that group. A card link would therefore drag the tab it was clicked in to the new group. `noshare=1` makes the new tab display-only on load, like the shared-group read. Probe I0 (control: a plain link does write) and L2 (a noshare load writes nothing) prove it. noshare stays in the new tab's address bar, so a reload stays display-only; a later explicit mode or n change in either tab still syncs as usual.
