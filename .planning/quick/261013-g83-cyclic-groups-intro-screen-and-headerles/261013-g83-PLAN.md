# Cyclic Groups: intro screen, then the full-screen desktop without the site header

## Context
The Cyclic Groups tool (`Cyclic Groups/cyclic-groups.html`) is now a windowed desktop that fills the browser window under the site header. The user wants an intermediary step whenever someone goes to the tool. It has two paragraphs:
1. What the tool does: its capabilities, interface and basics.
2. A note that the tool is effectively a full-screen application. It is best used in full screen, the site header is hidden either way, and visitors get back to the rest of the site with the browser's Back/Forward buttons.

Decided with the user:
- The desktop hides the site header and fills the whole window.
- Entering is a button that opens the tool **and** goes full screen.
- Paragraph 2 uses the polished wording below.
- Strings are English first (Cyclic Groups rule).

**Why it's a screen inside the tool page, not a separate page:** a browser only allows full screen in response to a click on the same page. Full screen is also dropped on navigation, so a button on a separate page could not open the tool in full screen. The intro is therefore the first screen of `cyclic-groups.html` itself:
- It shows with the normal site header, so language and day/night can still be set there.
- Its button hides the intro and the header and takes the desktop full screen, in one click.
- Back from the intro leaves the tool as usual.

The URL stays the same, so the nav links, the home card and the cross-links from other tools need no change.

## Changes (`Cyclic Groups/cyclic-groups.html` only; `_Cyclic Groups` is untouched)
1. **Intro screen markup:** a `<section class="cg-intro" id="cg-intro">` after the site header, with:
   - `<h1>` "Cyclic Groups" (existing `cyclicGroups.heading`);
   - two `<p>` paragraphs (`data-i18n`);
   - one primary button, `#cg-enter`, labelled "Open Cyclic Groups in full screen".

   Styled as a centred reading column using the palette tokens only, like the other pages' `.page-header`/`.lede`. Shown only on the top-level desktop page (`is-desktop`, not `ringwin`/`preview`/`isopane`).
2. **States:**
   - `:root.is-desktop:not(.is-entered)` shows the intro and the site header, and hides `.diagram-frame`.
   - `:root.is-entered` hides the intro and `.site-header`. The frame's inset becomes `0` (drop the `--desk-top` offset), so the desktop fills the window.
   - Only the windows' first layout waits for entering, because windows are sized as fractions of the desktop. After entering, run `syncWindows()`/`fitDesk` once more so the windows use the full size.
3. **Enter button:** adds `is-entered`, then calls the existing full-screen path (`diagramFrameEl.requestFullscreen`, as `#fullscreen-btn` does) inside the same click. If the browser refuses or lacks full screen, the desktop still fills the window. Focus moves into the Ring window. Leaving full screen later (Esc, or the corner button) keeps the header hidden; the corner button can go full screen again.
4. **Every visit shows the intro:** a page load always starts on the intro. Back from the desktop leaves the page. There's no "don't show again" (not requested).
5. **Tab title:** the existing `syncTabTitle` (front window) applies only after entering. Before that, the tab reads "Cyclic Groups".
6. **Strings** (en block of `assets/i18n/cyclic-groups.js`, added to the header comment's English-first list): `introAbout`, `introFullscreen`, `introEnter`.
   - **introAbout:** "Cyclic Groups turns a group into a ring of beads, one bead for each element. Choose a modulus and an operation — addition modulo n, or multiplication of the units modulo n — then pick an element: its chords walk around the ring, and when they reach every bead that element generates the whole group, which makes the group cyclic. The tool works like a small desktop. The Ring window holds the group's controls and its ring; drag it, resize it, and open more Ring windows to compare groups side by side. The Numerical list shows the subgroup each element generates, and an isomorphic group can be opened beside the ring and locked to it with the padlock, so the two turn, colour and highlight as one."
   - **introFullscreen:** "Because this tool has so many controls, it is really a full-screen application. It is best used in full screen, and the website's usual header is hidden either way. To get back to the rest of the website, use your browser's Back and Forward buttons instead of the header. Have fun!"
   - **introEnter:** "Open Cyclic Groups in full screen".
7. **Checker:** the page keeps its `site.nav`/header markup (the header is only hidden), so `i18n-check.js --header`/`--switcher-present` still pass.
