# Quick 261013-g83: Cyclic Groups intro screen, then the full-screen desktop without the site header

The Cyclic Groups desktop now opens on an intro screen every time it loads. The site header stays visible on the intro. Its button hides the intro and the header and takes the desktop full screen in the same click; the desktop fills the window either way.

## What changed
- **Markup:** `<section class="cg-intro" id="cg-intro">` sits right after the site header. It holds an `<h1>` (`cyclicGroups.heading`), two paragraphs (`introAbout`, `introFullscreen`) and the primary button `#cg-enter` (`introEnter`, with the full-screen icon). All of it is bound with `data-i18n`.
- **CSS (palette tokens only):**
  - `.cg-intro` is hidden by default. It shows only under `:root.is-desktop:not(.is-entered)`, so `ringwin`, `isopane` and `preview` pages never show it.
  - Before entering, `.app` is taken out of the page flow (`position:fixed`, `visibility:hidden`, `pointer-events:none`, its iframes forced hidden), and the page can scroll.
  - `:root.is-entered` hides `.site-header` and sets the frame's inset to `0`.
- **JS:**
  - `cgEntered` and `enterDesktop()`: adds `is-entered` and requests full screen of `diagramFrameEl` the same way as `#fullscreen-btn`, catching a refusal. It then runs `syncWindows()` to refit the windows to the whole window, focuses the first visible control in the Ring window and calls `syncTabTitle()`.
  - `syncTabTitle()` shows `cyclicGroups.title` on the intro.
  - The F8 split shortcut is ignored while the intro is up.
- **i18n:** `introAbout`, `introFullscreen` and `introEnter` are in the en block, with the exact strings from the plan. They are also added to the header comment's English-first list.

## Decisions
- The desktop waits behind the intro with `visibility:hidden` rather than `display:none`. The windows are laid out against the real desk size under the header, so nothing measures a zero-size desk. Entering only changes the frame's inset, which is the same path as an ordinary window resize, handled by the `ResizeObserver` and `syncWindows()`. Saved window geometry (`cyclic-groups-fs-windows`) was checked byte-identical before and after entering.

## Verification
- `i18n-check.js --header` PASS (19 pages). `--switcher-present` PASS (19 pages).
- `--coverage --all` reports exactly 30 LANG-KEYSET findings, one per non-English language. Each lists only the English-first keys: introAbout, introEnter, introFullscreen, isoLockOpenGroup, isoLockOpenSub and subColor*.
- Headless Chrome, 1500×1000:
  - **On load:** intro and header visible, frame hidden, title "Cyclic Groups".
  - **After `#cg-enter`:** intro and header hidden, frame at 0,0,1500,1000, Ring window refit (top 30, height 940), full screen granted, focus on `#n-input` inside the Ring window.
  - **Leaving full screen:** the header stays hidden and the frame keeps filling the window.
  - **Language switch on the intro:** nl changes the heading and the tab title.
  - **No intro in iframes:** isopane, ringwin and `preview=1` pages report the intro as `display:none`.
  - zero console errors.
- **Regression scripts** (isofix, unlink, rotsync, unlockopen, midbtn), each run after first clicking `#cg-enter`:
  - The first four give output identical to HEAD.
  - midbtn's absolute y values move up by about 26–50 px because the desk now starts at 0. The relations it checks are unchanged: button centred on the divider, the gap between padlock and button, absolute vs static positioning and the merged flags.
  - One parallel run of rotsync flaked (the iso pane was not yet open after 3 s under load). It matched HEAD exactly when run alone and in a second parallel run.

## Deviations from Plan
None in behaviour. Two small additions: F8 is ignored behind the intro, and the enter button carries the full-screen icon.

## Notes
- If the browser restores the page from its back/forward cache, the page comes back already entered, without full screen. A fresh load always starts on the intro.
- Hebrew, Arabic and Sorani show the English intro paragraphs (English-first fallback) in an RTL page. This is expected until the catch-up translation.
