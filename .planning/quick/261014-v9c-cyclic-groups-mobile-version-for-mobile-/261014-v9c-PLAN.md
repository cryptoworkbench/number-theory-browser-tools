<objective>
Make Cyclic Groups usable on a phone: one page, two modes. A browser that reports itself mobile gets the stacked single-column page (the layout that already sits under the windowed desktop), straight to the tool, with the site header kept; every other browser gets today's windowed desktop, unchanged.

Purpose: the tool now links itself to phones (the intro's QR code), but the windowed desktop is unusable on a phone. The stacked layout is close to usable (see the baseline screenshot) and needs a mode switch plus a phone pass: overlaps, ring size, tap targets, and touch gestures that do not trap page scrolling.

Output: detection + mode switch in `Cyclic Groups/cyclic-groups.html`, a `:root.is-mobile` CSS block, a handful of `IS_MOBILE`-guarded JS changes, two verification harnesses in the task directory, screenshots in the task directory, and one clause in `CLAUDE.md`.

Locked decisions honoured (from the orchestrator's planning context, cited as LD-1..LD-8):
- LD-1 One page, no second file. Mobile = `navigator.userAgentData && navigator.userAgentData.mobile === true`, else the user-agent regex `/Mobi|iPhone|iPod/`; tablets and iPadOS-desktop-UA get the desktop. Detection runs in the head pre-paint script and the JS `IS_DESKTOP` agrees through one source (the class). `?mobile=1` / `?mobile=0` override for one load, never persisted.
- LD-2 Mobile mode: no `is-desktop`, no intro, site header stays, root class `is-mobile`. Desktop mode behaviourally unchanged; every new CSS rule scoped under `:root.is-mobile`.
- LD-3 "Functioning": audit 360-430 px top to bottom; fix overlaps, horizontal overflow, tap targets under ~40 px where cheap, ring sized to the viewport width, readable legend/toggles. Ring drag must not trap vertical page scrolling; the planner's choice is stated in Task 2.
- LD-4 Desktop-only features (Ring windows/iframes, snapping windows, true full screen, scratch pads, right-click menus) may be hidden in mobile mode; the listed core features must work.
- LD-5 No new user-visible strings unless unavoidable; any such string is English-only (en block of `assets/i18n/cyclic-groups.js`, listed in that file's header comment).
