## The spec (Cyclic Groups/Formula_Map, untracked, the user's — read it first, never edit or commit it)

Positions: JN, GCD (short), GCD (full), LCM (short), LCM (full), a, a2, GCD (SLU), LCM (SLU). Steps = number of top-level "=" after the left side. Agreed examples, ℤ/12ℤ, base 1:
- h = 9 (log₁ 9 = 9, representative r = −3): JN `|⟨9⟩| = 4`, `[G : ⟨9⟩] = 3`. GCD full `|⟨9⟩| = |G| / gcd(|G|, log₁ 9) = 12 / gcd(12, log₁(1⁹)) = 12 / gcd(12, 9) = 12 / 3 = 4`, index `gcd(|G|, log₁ 9) = gcd(12, log₁(1⁹)) = gcd(12, 9) = 3`. GCD short drops the step writing h as g^q. a: `|G| / |log₁ 9| = 12 / |log₁(1⁻³)| = 12 / |−3| = 12 / 3 = 4`, index `|log₁ 9| = |log₁(1⁻³)| = |−3| = 3`.
- h = 3: a2 `|G| / log₁ 3 = 12 / log₁(1³) = 12 / 3 = 4`, index `log₁ 3 = log₁(1³) = 3`; a writes `12 / |3|` (bars kept for a positive r).
- GCD (SLU) (ℤ/nℤ only, h as itself, 0 taken as n): `|G| / gcd(|G|, 9) = 12 / gcd(12, 9) = 12 / 3 = 4`, index `gcd(|G|, 9) = gcd(12, 9) = 3`; LCM (SLU) `lcm(|G|, 9) / 9 = lcm(12, 9) / 9 = 36 / 9 = 4`.
- In (ℤ/nℤ)* the full forms write |G| as φ(n) in the step that writes h as g^q (today's shape); short forms give the cardinality's value at once.
- Edges: double (always): JN⇄GCD(short)⇄GCD(full), JN⇄LCM(short)⇄LCM(full). Single (conditional): GCD row ⇄ a and LCM row ⇄ a (the X between short and full) when a is open; a ⇄ a2 when a2 is open; JN ⇄ GCD(SLU) and JN ⇄ LCM(SLU) for ℤ/nℤ only.
