# Phase quick-261101-o20 Plan 01: a2 keeps the absolute value and skips the substitution step

a2 is now a with the logarithm substitution step taken out, the same way a short form is a full form without it. It keeps |log h|. It opens exactly when a opens, under every h and base, in (ℤ/nℤ)*, on curves and in ℤ/nℤ.

## What changed

- **`mapReach`**: `pos: r !== null`, the same as `abs`.
- **`mapFormula`**:
  - a2 size: `|G|/|log h| = n/|r| = n/a = m`. These are a's steps without its second one, so 4 steps.
  - a2 index: `|log h| = |r| = a`, so 3 steps.
- **`mapSettle`**: if a or a2 is shut, the knob goes to the full form of its row. The old "a2 to a" fallback is gone, because a always shuts together with a2.
- **Comments**: the map header, the mapReach, mapSettle and mapFormula step-count comments are updated to match.
- **Strings (en)**:
  - `formula.mapOrderPos` is now `|⟨h⟩| = |G| / |log_g(h)| = n / |r| = n / a = m`.
  - `formula.mapIndexPos` is now `[G : ⟨h⟩] = |log_g(h)| = |r| = a`.
  - `fmapPos` has the user's new tooltip.
  - No other language block carried these three keys, so nothing else changed. The gate config is untouched.

- The order formula reads `|⟨5⟩| = |⟨ℤ/13ℤ, ×⟩| / |log₂(5)| = 12/|−3| = 12/3 = 4`, which is 4 steps.
- The index formula reads `[⟨ℤ/13ℤ, ×⟩ : ⟨5⟩] = |log₂(5)| = |−3| = 3`, which is 3 steps.
- The absolute bars render, and there is no φ(13) or 2^−3 step.
- On the map, a2 and a are both open, and the sliders show compact / neither.
