# Quick 261101-so1: additive groups get the formula sliders, with a forked Complexity track

## Objective

The user's spec (`Cyclic Groups/ADDITIVE_GROUPS_FORMULAS_COMPLEXITY_SLIDER`):
ℤ/nℤ gets the same Complexity / Form preference slider pair as a cyclic
(ℤ/nℤ)* and a cyclic curve. Form preference is copied one to one. Complexity
gets a fourth slot for the SLS forms, on a forked track:

```
       2
O======O======O
1\\         //4
  \\===O===//
       3
```

1 JN, 2 compact, 3 compact SLS (skip the logarithm substitution), 4 complete.
Slot 3 is the `gcd-sls` / `lcm-sls` token by the form slider's row.

## Decisions

- D-01 `hasSliders(G)` becomes `hasMap(G)`: ℤ/nℤ draws the slider pair, and its
  map moves behind the same show-map toggle (`state.fmapOpen`, `fmapopen=1`).
  The open additive map keeps its two SLS rows (`reach.sls`).
- D-02 Complexity values: 0 JN, 1 compact, 2 complete as before, 3 compact SLS
  (`data-v="3"`). `fslOf` reads an SLS token as c = 3 with the form of its row
  (it used to read it as JN); `fslToken(3, v)` gives `lcm-sls` / `gcd-sls`.
  The forked slider is built only where `reach.sls` (additive); EC and
  multiplicative keep the three-slot straight track unchanged.
- D-03 Neither + slot 3 has no node: a Complexity move to slot 3 while the
  form is neither (at JN the remembered one), and a Form move to neither
  while Complexity is slot 3, are refused: the knob balks, the slot-3 notch
  and the neither notch flash `is-flash-no` (the ix2 refusal record
  `fslRefuse` with `v: 3`, no node and no base hint since no base helps), and
  each carries a new tooltip. A double-click forces it: on slot 3 the form
  goes to the row neither was entered from (`{row}-sls`); on neither the
  complexity goes to compact (a2 on that row), through `forceMapPosition`
  when the base leaves a2 shut.
- D-04 Keys on the forked slider: Left/Right follow the branch the knob is on
  (top 0-1-2 by default, bottom 0-3-2 from slot 3), Up/Down switch between
  compact and slot 3 (nothing elsewhere), Home/End go to JN/complete.
  Arrows onto a refused slot are refused, as ix2's blocked notch.
  `aria-valuemax` is 3 and `aria-valuetext` names the slot.
- D-05 Drawing: the top line is the existing `.fsl-track`; the bottom branch
  (45° diagonals from JN and complete down to a straight run through slot 3)
  is a small SVG under the slots in the same track colours. The three top
  captions sit above their slots, slot 3's under it, so nothing crosses the
  branch. The knob is placed from `--v` by CSS; a move glides along the
  branch path (Web Animations through the path's waypoints, the 2↔3 move
  straight down/up, which is not drawn), from rest, from a drag release and
  from a knob caught mid-glide by a rebuild. A drag follows the drawn path.
- D-06 Generator row (boxes, padlock, wheel switch) hides when every shown
  formula is at JN or an SLS form (one rule for every group).
- D-07 New strings English only (`fslCompactSls`, `fslCompactSlsText`,
  `fslCompactSlsTip`, `fslSlsNeither`, `fslNeitherSls`); the gate config is
  untouched; gates stay 31 / 4 / 109.
