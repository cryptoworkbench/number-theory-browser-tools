# Quick 261101-u47: Short slot, no Complexity caption, formula map in its own window

## Objective

On every group with formula sliders: the Complexity slider's JN slot reads
"Short", the "Complexity" caption goes (the slider keeps its aria-label),
the map icon beside the sliders goes, and the formula map opens from the
formula card's right-click menu into a floating window of its own (title
"Formula map", minimize and close in its top-right corner) that minimizes
into the bottom bar like the polygon and lap-key windows and stays live.

## Decisions

- D-01 Internal token stays `jn`; only the slider's slot label (new
  `fslShort`), its spoken value and its tooltip (new `fslShortTip`) say
  Short; `fslFormInert`'s English value says Short. The map's own JN node
  keeps its label. New strings English only; gate config untouched.
- D-02 Window: a `.curve-plot.fmap-win` section in the ring body beside the
  other plot windows, moved by `plotWindow` (drag by head or frame, not by the
  map), minimize `_` (`lapKeyMin`) and close `x` (`dhClose`), the
  `.is-close` look of the Diffie–Hellman window. Its maps are the ones
  `syncSubFormula` builds (`formulaMap`), each under a small caption, so
  slider / map / base-box changes, flashes, forcing and the route band act on
  them as before; snapshot/carry, refusal and force lookups search the
  window as well as the formula card.
- D-03 Context menu: the formula card's right-click menu (syncFormulaCtx)
  gets "Show the formula map" / "Hide the formula map" (existing
  `fslMapShow` / `fslMapHide`). Shown = open and not minimized; Show on a
  minimized window restores it.
- D-04 Persistence: `fmapopen=1` = window open; `fmapmin=1` (only with
  fmapopen) = minimized, the way the polygon window keeps its state in the
  URL. A new Ring window or pane drops both.
- D-05 Mobile (no windows): the formula card's menu also answers a
  `contextmenu` there (Android's long press); its item shows / hides the
  maps inline under the sliders as before. iOS fires no contextmenu, so
  there it is reachable only through `fmapopen=1`.
- D-06 Isomorphism pane: its maps stay inline (its windows would need the
  host bar protocol); the same menu item toggles them, and the one shared
  `fmapOpen` setting still opens the host's window too. Ring windows run the
  same page code and get the window as is.
