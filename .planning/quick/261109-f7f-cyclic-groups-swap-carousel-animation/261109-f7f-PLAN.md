# Quick task 261109-f7f: swap carousel

Swapping the left and right panes animates only the circles of beads as a carousel turning
about the vertical line between the panes (left ring in front, right ring behind, both facing
the viewer); text and controls stay until the animation completes, then snap to the other side.

## Task 1
- files: Cyclic Groups/cyclic-groups.html
- action: startSwapSpin asks the pane for its ring (ringsnap message, XMLSerializer), copies both
  rings into a fixed overlay with ids prefixed, hides the real rings, animates cos/sin carousel
  for 700 ms, then runs swapIsoRings(true); loadIsoFrame(keepOld) holds the old frame until the
  new one loads.
- verify: Chrome, swap ℤ/13ℤ× ↔ ℤ/12ℤ+: sampled copy positions, handoff timing, no errors.
