<objective>
Add an animated Extended Euclidean algorithm to the Equivalence Wheel. The animation plays over the dimmed wheel, and a step table plus narration sit under it.

The idea it teaches: running extended Euclid on (N, a), every remainder satisfies r_i ≡ t_i·a (mod N). On the wheel, t_i hops of size a from 0 trace the raw integer t_i·a. Ring k holds the raw integers kN..(k+1)N−1, so that raw value sits in ring floor(t_i·a / N) of wedge r_i, and reducing mod N is literally a slide inward along the wedge to ring 0. Negative t_i·a lives "below zero", inside the hole, and slides outward. The finale either lands a hop trail on 1 and names a⁻¹, or, when gcd(a, N) = g > 1, shows the orbit {0, g, 2g, …} that hops of a can never leave.

Purpose: the user asked (verbatim) "Can you make a visualization of the Extended Euclidean algorithm using the congruence wheel? When activated, an animation will play out over/in the congruence wheel background, using arrows, highlighting of cells, reductions, etc. Be creative". The orchestrator's design brief (§1 controls, §2 overlay, §3 per-step beats, §4 table and narration, §5 finale, §6 styling, §7 i18n, §8 verification) is the source this plan implements. Each task cites the brief section it covers.

Output: an extended `Equivalence Wheel/equivalence-wheel.html`, 22 new `wheel.euclid*` keys in all 31 languages in `assets/i18n/equivalence-wheel.js`, a CDP verification harness, and a one-clause CLAUDE.md update.
</objective>
