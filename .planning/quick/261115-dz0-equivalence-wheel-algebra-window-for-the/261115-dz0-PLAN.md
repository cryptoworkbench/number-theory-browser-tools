# 261115-dz0: Algebra window for the Extended Euclid animation

User request: "Add to it a window which will keep track of all of the algebra for me, basically as reference
sketchpad which shows the normal, textual summary of how the algorithm is performed/executed. This is needed
because otherwise it'll not be clear to the user what the happenings on the wheel mean!"
English only (user instruction 2026-11-15): new keys go in the `en` block only.

## Task 1: Algebra window

- files: `Equivalence Wheel/equivalence-wheel.html`, `assets/i18n/equivalence-wheel.js`
- action:
  - An `<aside id="euclid-pad">` window, position fixed (top right under the header, a bottom sheet under 760px):
    a title bar "Algebra" you can drag (clamped to the viewport), a minimise button, and a scrolling body.
    It opens on Run and hides on Exit; it is hidden in print and never part of an export.
  - Lines are built from the run (`buildRun` also keeps s), each tagged with the beat that reveals it:
    intro (goal, invariant r = s·N + t·a, r₀, r₁), and per step divide (rⱼ = q·rⱼ₊₁ + r, solved for r, or the
    stop line and gcd), coef (t and s recurrences, r = s·N + t·a), reduce (t·a = r − s·N ⇒ r ≡ t·a mod N),
    then the finale (Bézout, the inverse with a check, or the no-inverse argument) and the back-substitution chain.
  - Lines up to the current beat show; the current beat's lines are highlighted and scrolled into view. Each line
    has a left bar coloured like its arrows (divide role-input, coef role-active, reduce/finale role-result).
    Clicking a line pauses and jumps to its beat.
  - Prose goes through translate() whole-sentence templates (new `wheel.euclidPad*` keys, en only); formulas are
    notation built in JS, LTR under `:root[dir="rtl"]`.
- verify: headless Chrome (euclid-check harness style): N=26 a=7 shows the Bézout identity 3 · 26 − 11 · 7 and
  7⁻¹ ≡ 15; N=12 a=8 shows the no-inverse argument; clicking a line jumps; screenshots in both themes.
- done: the window tracks every beat, with no page exceptions.
