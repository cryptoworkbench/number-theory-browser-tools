# Finite Groups: the wheel's % n turns with the ring

With "Keep the numbers readable at every turn" off, the congruence wheel's centre label (% n) is no longer turned back upright after each turn; it stays as drawn (upright with the identity at the top) and turns with the ring, like the wheel's numbers and aᵏ's numbers.

- drawRingWheel: drop the counter-rotation of `.dhc-wheel-mod` on a full draw and on the kept-wheel path.
- With the option on, g.turn is 0, so nothing changes there.
