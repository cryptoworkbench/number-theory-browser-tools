Elliptic Curve Diffie-Hellman

The whole point set of a small elliptic curve over a prime field, plotted as a scatter. Alice and Bob walk across it by scalar multiplication and land on the same point from opposite directions — the same protocol as Diffie-Hellman Key Exchange, in a group whose elements are points instead of numbers.

•

How this works

A curve y² = x³ + ax + b mod p has a set of points that forms a group: pick two points, draw the line through them, and the line meets the curve at exactly one more point — reflect that point across the horizontal midline and you have their sum. Scalar multiplication kG means adding G to itself k times using that construction. Alice picks a private scalar a and computes A = aG; Bob picks b and computes B = bG. They trade A and B in the open, then each multiplies the value they received by their own private scalar — aB and bA land on the exact same point, the shared secret, even though Eve saw A and B cross the wire.

This is a teaching demo: toy-sized curves (p ≤ 199), private scalars drawn with Math.random (not a cryptographic random source), and the raw shared point is displayed here rather than run through a key-derivation function. Never reuse anything on this page for anything real.
